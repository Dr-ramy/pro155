# برنامج مقترح في الجغرافيا قائم على نموذج درايفر
## لتنمية مفاهيم الأمن الفكري والوعي بالأحداث الجارية لدى طلاب المراحل المتوسطة بدولة العراق

---

### 🌟 نظرة عامة
تم بناء هذا المشروع بدقة وفقاً للتصميم الهندسي والتربوي المحدد في وثيقة المشروع (`app154.txt`).  
التطبيق ليس مجرد موقع لعرض المحتوى أو نظام اختبارات تقليدي، بل هو **بيئة تعلم تفاعلية (Interactive Learning Environment)** تحول كل قضية جغرافية أو حدث جارٍ إلى **رحلة استقصائية متكاملة (Mission)** قائمة على **المراحل الخمس لنموذج درايفر البنائي (Driver's Model)**.

---

### 🏗️ الهيكل التقني والمكتبات
- **الواجهات والتنسيق**: HTML5 + CSS3 + Bootstrap 5 RTL + Bootstrap Icons
- **الخطوط**: خط `Cairo` و `Tajawal` العربي الحديث من Google Fonts
- **البرمجة والتفاعل**: Vanilla JavaScript ES6 (بدون أطر عمل معقدة لضمان السرعة والسهولة)
- **إدارة الحالة والبيانات**: `AppState` داخل ذاكرة JavaScript و `sessionStorage` (دون الحاجة لقاعدة بيانات أو خادم خارجي).

### 🧭 المراحل التربوية الخمس لنموذج درايفر المنفذة برمجياً
1. **التهيئة واستثارة الأفكار السابقة (Elicitation)**:
   - عرض موقف محفز / خبر عاجل متداول.
   - تساؤلات الطالب الأولية.
   - **مقياس الموقف (Opinion Scale)**: تسجيل مستوى التصديق المبدئي من 1 إلى 5 دون إصدار حكم صح/خطأ.
   - تسجيل التفسير الأولي وحفظه في الذاكرة.

2. **استكشاف الأفكار والأدلة (Exploration)**:
   - **مختبر الأدلة (Evidence Lab)**: بطاقات أدلة رسمية، صور أقمار صناعية، تحاليل مختبرية، وتحليل منشورات شبكات التواصل.
   - **عدسة التحقق (Verification Lens)**: أداة وقائمة فحص المعايير الخمسة للأمن الفكري الرقمي مع مؤشر قياس فوري (Gauge %).
   - **خريطة الحدث التفاعلية (Interactive Event Map)**: خريطة جغرافية تفاعلية للعراق بنقاط (Hotspots) تربط المكان بالحدث وبالدليل الجغرافي.
   - **خط الزمن (Timeline)**: ترتيب تطور الأحداث زمنياً من منشأ الأزمة وحتى الاستجابة.
   - **تصنيف المعلومات**: تمييز (حقيقة علمية / رأي شخصي / ادعاء غير مثبت / شائعة مضللة).

3. **إعادة بناء الأفكار والصراع المعرفي (Restructuring)**:
   - **مواجهة الصراع المعرفي**: مقارنة تقدير الطالب الأولي بما أثبتته الأدلة العلمية.
   - خيارات: التمسك بالرأي، أو تعديله، أو طلب **دليل التحدي الإضافي (Bonus Evidence)** لفتح وثائق إضافية.
   - **ربط الادعاء بالدليل**: تفنيد الشبهات بالحقائق الجغرافية.
   - **شبكة الأسباب والتداعيات**: تصنيف الأسباب الطبيعية، الأسباب البشرية، والآثار البيئية والمجتمعية.

4. **تطبيق الفهم في موقف جديد (Application)**:
   - **غرفة القرار (Decision Room - Signature Activity)**: سيناريو أزمة واقعي متفرع لاختبار رد الفعل الميداني عند مواجهة شائعة تمس أمن الوطن واستقراره مع حساب عواقب كل قرار.
   - **صياغة الحكم النهائي المدعوم بالأدلة**: (الحكم + أقوى دليل + التعليل العلمي).

5. **مراجعة التغير في الأفكار (Review / مرآة التفكير)**:
   - **مرآة التفكير (Thinking Mirror)**: مقارنة مباشرة جنبًا إلى جنب بين (ما كنت تعتقده في البداية) و(ما أصبحت تعتقده وتثبته الآن بالأدلة).
   - تحديد العوامل الحاسمة التي قادت إلى هذا التحول الفكري والمعرفي.

### 📊 محاور القياس التحليلي داخل لوحة المهارات (`results.html`)
- **أبعاد الأمن الفكري الستة**:
  1. التحقق من المعلومات
  2. التمييز بين الحقيقة والرأي والادعاء
  3. التفكير النقدي في الأدلة
  4. مقاومة الشائعات والتضليل
  5. الموضوعية وتعدد وجهات النظر
  6. إصدار الحكم المستند للأدلة
- **أبعاد الوعي بالأحداث الجارية الستة**:
  1. الوعي المكاني (الخرائط والمواقع)
  2. الوعي الزمني (التسلسل الزمني للأحداث)
  3. الوعي السببي (تفسير الظواهر الجغرافية)
  4. الوعي بالأطراف والجهات الفاعلة
  5. الوعي بالنتائج والتداعيات
  6. الوعي بالسياق العام للقضية
- **أوسمة الجدارة الفكرية المكتسبة** وإمكانية **طباعة التقرير أو حفظه كملف PDF**.
