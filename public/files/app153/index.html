2. قائمة تحقق المتطلبات الوظيفية (R1 – R8)
  • R1 — اختيار القضية البيئية: 3 قضايا عراقية (حارس النهر، أنقذ أرضنا، مدينتنا أجمل).
  • R2 — تحديد الأسباب: اختيار متعدد مع تصنيف علمي وتفسير لكل عامل.
  • R3 — اختيار الحلول: بطاقات تفاعلية توضح نوع التدخل والفائدة والقيود.
  • R4 — تقييم الخطة: تقييم نوعي وفق ملاءمة السبب والحلول، لا مجرد عدد الاختيارات.
  • R5 — تغيير المشهد: طبقات SVG ديناميكية تتغير كل طبقة فيها فقط وفق القرار المرتبط بها.
  • R6 — التغذية الراجعة: توضيح نقاط القوة والقصور والخطوة التالية المقترحة.
  • R7 — التأمل الجمالي: مهمة تقييمية مستقلة (0–2) حول التناسق والتنوع وقيمة الجمال البيئي.
  • R8 — تسجيل الأداء: حفظ محلي وتصدير CSV/JSON مع حماية خصوصية الطلاب.
